# SEG 3502 - Laboratoire 2 : calculatrice Spring MVC

Application Kotlin / Spring Boot / Thymeleaf. Quatre opérations, validation des nombres et de la division par zéro.

## Démarrage
Installer un JDK 21 et Gradle, puis exécuter `gradle bootRun`. Ouvrir http://localhost:8080.

## Tests
`gradle test` (nécessite un accès aux dépendances Maven). Aucun test n'a été exécuté dans le présent environnement.

## Travail demandé
Il s'agit de l'exercice de calculatrice, et non de l'exemple pédagogique du convertisseur de température.
